Warning: untested compatibility

This override replaces Jellyfin's entire Web interface with the copy bundled by this plugin. After a Jellyfin update, that copy may be older and missing newer fixes, including security fixes. Browsing, playback, sign-in and dashboard controls may stop working.

Enable it only if you accept these risks. It does not make an untested version supported, repair incompatible server APIs, or make the plugin load on an incompatible server.

This is a server-wide setting. It affects everyone using this server's Web interface and stays enabled across restarts and future Jellyfin upgrades until you turn it off.

To revert, turn the override off, save and hard-refresh Jellyfin in every open tab. If cached files remain, clear the site's cached data and sign in again. If the dashboard no longer opens, stop Jellyfin and disable the override in this plugin's configuration file, or remove this plugin before restarting.

Off by default. Turning this on bypasses only the bundled Web version restriction. Save, then hard-refresh Jellyfin in every open tab to load the selected interface. Clear the site's cached data if needed; no server restart is needed.
